# 🧳 여행 플래너 (Trip Planner)

지도에 일차별 여행 코스를 그리고, 시간과 메모로 일정을 계획하는 웹앱입니다.
설치 없이 브라우저에서 바로 쓸 수 있고, 데이터는 내 기기에만 저장됩니다.

🔗 **바로 사용하기:** https://ttaee821rr.github.io/trip-planner/

## 주요 기능

### ✅ 지금 쓸 수 있는 기능
- **일차별 코스 그리기**: 지도를 눌러 장소를 추가하면 번호 핀과 선으로 코스가 이어집니다.
- **일차별 색 구분**: 1일차, 2일차마다 색이 달라서 `전체` 탭에서 한눈에 비교할 수 있습니다.
- **시간 계획**: 장소마다 시간을 적으면 시간 순서대로 자동 정렬됩니다.
- **메모**: 입장료, 할 일 등 장소별 메모를 남길 수 있습니다.
- **날짜 표시**: 출발일을 입력하면 일차 탭에 날짜와 요일이 표시됩니다. (예: 1일차 · 11/20(금))
- **길찾기**: 장소마다 카카오맵 길찾기로 바로 연결됩니다.
- **자동 저장**: 새로고침하거나 브라우저를 닫아도 데이터가 남아 있습니다.

## 사용 방법
1. 맨 위에 여행 이름과 출발일을 입력합니다.
2. `1일차` 탭을 고르고 지도에서 가고 싶은 곳을 누릅니다.
3. 장소 이름, 시간, 메모를 입력하고 **저장**을 누릅니다.
4. `+ 일차 추가`로 다음 날 일정을 만듭니다.
5. `전체` 탭에서 여행 전체 코스를 확인합니다.

## 기술 스택
| 구분 | 사용 기술 |
|---|---|
| 화면 | HTML, CSS, JavaScript (빌드 도구 없음) |
| 지도 | [Leaflet](https://leafletjs.com/) 1.9.4 + [OpenStreetMap](https://www.openstreetmap.org/) |
| 저장 | 브라우저 localStorage |
| 길찾기 | 카카오맵 공개 링크 |
| 배포 | GitHub Pages |

현재 버전은 API 키 없이 동작합니다.

## 내 컴퓨터에서 실행하기
```bash
git clone https://github.com/YOUR_GITHUB_ID/trip-planner.git
cd trip-planner
python3 -m http.server 5500 --bind 127.0.0.1
```
브라우저에서 http://127.0.0.1:5500 을 엽니다. 끌 때는 터미널에서 `Control + C`를 누릅니다.

> `index.html`을 더블클릭해서(file://) 열지 마세요. 위치 기능 등은 로컬 서버(http://127.0.0.1)나 HTTPS에서만 동작합니다.

## 데이터와 개인정보
- 여행 데이터는 **사용하는 기기의 브라우저(localStorage)에만** 저장되며 서버로 전송되지 않습니다.
- 다른 기기나 다른 브라우저와는 데이터가 공유되지 않습니다.
- 지도를 볼 때 OpenStreetMap 서버에 지도 이미지를 요청하고, 길찾기를 누르면 카카오맵에 장소 좌표가 전달됩니다.
- 사용자가 입력한 글은 `textContent`로 화면에 넣어 스크립트 삽입 공격(XSS)을 막습니다.
